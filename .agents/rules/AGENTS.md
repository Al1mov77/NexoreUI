ПРИОРИТЕТ
Эти правила выше любых скиллов, плагинов и твоих привычек (uiux, Framer Motion и т.п.). Если скилл предлагает эффект, которого здесь нет в разрешённых, не делай его. При сомнении спроси, не угадывай. Ничего не добавляй "от себя": ни фич, ни эффектов, ни текстов.

1. ФОРМАТ КОДА (шаблоны, компоненты, реестр, всё, что получит пользователь)
- Шаблон это ОДИН файл templates/<slug>.tsx. Чистый TSX, "use client" только если нужен.
- В коде НЕТ комментариев вообще: ни //, ни /* */, ни {/* */} в JSX, ни JSDoc, ни TODO/FIXME, ни eslint-disable, ни @ts-ignore/@ts-expect-error. То же для CSS и JSON. Объяснения живут только в документации (MDX), не в коде.
- TypeScript strict. Никаких any (явных и неявных), as any, as unknown as T, лишних non-null (!). Пропсы через interface, без React.FC. Данные наверху файла константами as const + satisfies с явными типами.
- Без console.*, без мёртвого кода, без неиспользуемых импортов и переменных, без закомментированного кода, без заглушек (Lorem ipsum, Acme, John Doe, Company Name).
- Код отформатирован prettier. Имена конкретные (bookingRows, а не data1). Один компонент на одну ответственность, компоненты внутри файла небольшие.
- Цвета только через токены Tailwind (bg-background, text-foreground, border-border, bg-primary, text-muted-foreground и т.д.). Никаких hex, rgb(), hsl() литералов, named-цветов Tailwind (cyan, violet, blue-500...), shadow-[...] с цветом, градиентов-украшений. Исключение: статусы через bg-success/bg-warning/bg-info/bg-destructive.
- Импорты только из: react, next/*, motion/framer-motion, lucide-react, и компонентов библиотеки @/components/ui/*. Новые npm-зависимости без моего разрешения запрещены.

- Палитра: zinc, чёрно-белая. Токены: --background, --foreground, --card, --muted, --muted-foreground, --border, --primary, --primary-foreground, --ring, статусные --success/--warning/--info/--destructive, --chart-1..5. Шрифты Geist и Geist Mono (через next/font или CSS-переменные --font-sans, --font-mono).

Состояния не только цветом: hover bg-accent, disabled opacity-50, focus-visible:ring-2 ring-ring ring-offset-2 ring-offset-background у всех интерактивных элементов, ошибка = border-destructive + текст.

4. АНИМАЦИИ (Framer Motion, только по делу)
- Разрешено: появление при скролле (opacity + translateY не больше 24px, 0.5–0.8s, ease-out, stagger не больше 0.08s), прогресс скролла, count-up один раз, sticky-сценарии, layout-переходы, раскрытие аккордеона, фоновые волны WebGL там, где это указано в задаче.
- Запрещено: spring с отскоком, hover-scale больше 1.02, parallax на всём подряд, 3D-наклоны, анимация каждого элемента, бесконечные циклы.
- Один заметный "wow-момент" на шаблон, остальное тихо.
- Всегда useReducedMotion: при reduce анимации выключены, контент виден сразу. Всё, что видно на первом экране, читается без ожидания анимации и без скролла.

5. ВИДЕО-ШАБЛОНЫ
- Файлы видео лежат не в TSX и не в пакете. В коде относительный путь /templates/<slug>/<имя>.mp4 (+ .webm и poster .jpg рядом).
- <video muted autoPlay loop playsInline preload="metadata" poster=...>. При prefers-reduced-motion показывать только poster. Нет data-URI видео, нет внешних абсолютных URL в коде.
- Требования к файлу: до 1080p, до 24 fps, не больше 6 МБ, без текста и логотипов внутри видео.
